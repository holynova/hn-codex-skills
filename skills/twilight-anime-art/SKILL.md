# 暮色动画插画

把同一种安静、温暖而略带怀旧的暮色氛围，应用到用户指定的题材。统一的是色彩关系、光线、绘画语言和情绪；泳池、棕榈、城市、冰饮、猫和落日天空都不是必需物件。

**五张随附例图是技能的必要组成部分，不得用文字摘要替代。** 每次开始使用本技能，先读取 [例图与观察要点](references/examples.md)，通过图像查看工具逐张查看以下五张图；当前上下文已经逐张看过时可复用，不必重复加载。

2. [海边列车](references/images/02-train.webp)：海岸、列车、候车人物。
3. [雨夜书店](references/images/03-bookstore.webp)：室内书架、雨窗、窗外行人。
4. [山间旅舍](references/images/04-lodge.webp)：木石建筑、雪山、溪流、休息人物。
5. [屋顶晚风](references/images/05-rooftop.webp)：近景人物、花盆、晾衣绳、城市。

## 风格中保持什么

| 维度 | 视觉规律 | 实现方式 |
| --- | --- | --- |
| 色彩 | 粉红、珊瑚、桃橙高光与靛蓝、紫色阴影相互呼应 | 大面积冷色环境＋局部暖光，青蓝作点缀；避免所有物体都套粉紫滤镜 |
| 光线 | 冷暖关系清楚，光源可信 | 夕光、窗灯、台灯或车灯有明确位置，暖光落到附近表面，远景逐渐偏冷 |
| 笔触 | 精细动画背景与绘画质感结合 | 清楚的细线、简化而准确的形体；云、树叶、织物、石材有细腻手绘纹理，避免照片锐化感 |
| 材质 | 质感与反射随物体变化 | 湿石路、玻璃、海面映光；木头、纸张、布料呈柔和漫反射，不把一切画成发亮塑料 |
| 空间 | 前、中、后景分层，有可进入的场所感 | 前景锚点、中景主体、远景深度；以遮挡、尺度、冷暖变化建立透视 |
| 情绪 | 宁静、有人生活过的温度、微小叙事 | 阅读、候车、休息、照料植物等自然动作，保留安静空间，不强加戏剧情节 |
| 人物 | 自然融入场景，身体与空间关系可信 | 姿态、衣褶表达动作；可远可近，也可无人，不固定性别、年龄或身份 |

这是视觉关系，不是固定色号或固定时间。暮色是默认方向；用户指定夜景、室内、清晨或别的配色时，保留冷暖光、笔触和安静情绪，并服从指定条件。室内画面不必硬塞大片天空。

## 从需求到图像

1. **确定主体。** 沿用用户的题材、人物、物件、尺寸和用途，仅缺少会影响结果的关键信息才提问。
2. **视觉校准。** 查看五张必需例图，识别跨场景共有的色彩、光线、笔触和空间层次，不直接复制例图场景。
3. **安排变化。** 多图任务先为每张列一行：场景、主体/动作、建筑或环境、前景物件、镜头、天气/光源。保留用户固定项，在其余维度安排明显差异；可简短告知方向，不强制额外确认。
4. **独立提示词。** 读取 [提示词结构与示例](references/prompts.md)，共享风格核心，分别描述各张的空间、动作和材质。注明参考图仅约束风格、氛围和绘画语言，不约束主体、物件或布局。
5. **实际生成。** 用户要求成图时使用可用图像生成工具，默认内置 imagegen。多张独立图分别调用，不用拼贴替代。支持图像参考时，选择与本张构图相关的一至两张随附例图作为风格参考传入；五张都先看，但不必全部传入每次调用。用户给的参考图也要标明角色，其明确要求优先。工具不支持图像参考时，可用已看图校准后的文字提示；没有生图工具时说明限制，不把提示词当作已生成图片。用户只要提示词时则交付提示词。
6. **看图复核。** 逐张查看结果，检查冷暖光、手绘质感、安静情绪、主体准确、肢体与建筑透视合理；整组检查明显差异，有问题只针对该图修正，不为统一风格把全组变成同一场景。
7. **保存交付。** 保存实际图像与最终提示词到用户指定目录或项目输出目录，展示图片并给出文件路径。只有用户要求网站或发布时才进行对应工作。

## 系列多样性

除用户指定的连续叙事、同一空间或角色一致性任务外，相邻图片宜在至少三个可变维度上发生实质变化：

- **场景尺度**：街道、室内、海岸、乡野、山地、交通空间等。
- **主体与动作**：独景、单人、多人；阅读、等待、漫步、劳动、休息等。
- **建筑与环境**：砖石、木构、玻璃、传统街屋、自然岩石等。
- **物件与材质**：书、行李、车辆、花草、器物、布料等，由题材决定。
- **镜头与布局**：远景、眼平、窗内向外、人物近景、俯视或低机位；改变主体位置与留白。
- **天气与光源**：干燥暮色、雨夜、蓝调时刻、室内台灯、车窗灯光等。

“泳池换个城市”“同一露台换天空颜色”“每张都摆前景冰饮与右侧客厅”通常不足以形成多样性。例图示范的是不同题材共享风格；它们的场景名单、猫和人物配置也不能成为下一次必须照抄的配方。

## 避免常见偏差

- 不把赛博朋克招牌、高饱和霓虹和光晕堆叠当作必需条件。
- 不只写“动漫风＋粉紫色”：同时描述光源、阴影、材质、线条和空间层次。
- 避免写实照片、光滑3D渲染、厚黑人物描边与环境绘画质感冲突。
- 人物动作简洁具体，检查手脚、坐姿与接触面；不为装饰随意塞人。
- 默认单幅完整画面、无水印或额外文字；用户要求文字时沿用其内容。
- 默认沿用例图的3:4竖幅；用户用途或明确比例优先，横幅也应保持完整构图。
