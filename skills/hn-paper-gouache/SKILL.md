# 纸纹平涂水粉插画

目标：让画面像在细密纹理纸上用不透明水粉画成的旅行插画。保留纸纹、色块与手绘边缘，让场景、季节和构图变化。**例图是技能的必要组成部分，不是可选附件。不能只凭“蓝天白云”判断风格。**

## 先看例图，再作图（必需）

相对路径从技能目录解析。先读取 [例图索引与观察说明](references/visual-examples.md)，核对 [图片清单](assets/examples/manifest.json)。每次新的作图任务，使用图像查看工具实际打开至少三张独立例图：

1. 基础锚点：`assets/examples/coastal-bus.jpg`。
2. 与目标场景最接近的一张。
3. 与前两张在配色、季节或视角上不同的一张。

同一批任务中复用已看过的图，不必为每张输出重复加载。仅阅读文件名、Markdown 或缩略联系表不算视觉校准。六张完整例图必须随技能安装；缺失时先恢复完整技能包，不把缺图的技能当成可用的文字版。环境不能查看图像时，说明无法完成视觉校准，不宣称已经按例图生成。

以下两张展示“相同笔触语言，不同场景和配色”；另外四张见例图索引：

例图只作**风格参考**。生成工具支持本地参考图时，传入基础锚点和目标近邻，标注“STYLE REFERENCES ONLY”，不复制原图主体摆位。用户照片用于内容或构图时另标角色，避免把写实质感带入风格。

## 固定的画风，变化的内容

| 固定的视觉语言 | 可以变化的场景参数 |
| --- | --- |
| 不透明、哑光水粉色块，细纸纹覆盖整张画 | 蓝海、城市、沙漠、树林、雪山、室内或其他环境 |
| 大形状先行，光面与阴影分成清楚色块 | 晴日、阴天、雨后、晨昏，以及用户指定的气候 |
| 自然略不齐的手绘边缘，不靠黑描边塑形 | 平视、仰视、俯视、近景、中景、远景 |
| 色彩干净，暖冷对照，少量强调色集中视线 | 蓝绿、橙青、赭蓝、冰蓝白、紫灰黄等关系 |
| 简化细节、清楚主体轮廓、前中后景层次 | 建筑、交通工具、小人物、动物或其他主体 |

- **材料**：opaque matte gouache；fine tactile watercolor-paper grain；少量干笔起伏。避免透明水彩大面积晕染、光滑矢量面、油画厚涂、仿旧脏污和粗重木刻刀痕。
- **塑形**：用色块、轮廓、遮挡和投影表现体积；阴影通常是钴蓝、青蓝或紫灰的独立形状，不用写实渐变和高光建模。
- **细节**：窗、瓦、树叶与波纹形成简洁节奏，不逐片写实刻画；纸纹不盖过形状，不像摄影噪点。
- **构图**：一处主要视觉焦点；用道路、河流、楼梯、桥梁或建筑边线引导视线。人物和车辆可作尺度参照，不必每幅出现。
- **天空**：晴日可用白色与浅青色云块，但巨型积云、大海、白房子和夏天都不是必要条件。无天空构图仍能保持画风。
- **默认画幅**：满版 2:3 竖图，通常 1024×1536；用户指定比例或用途时服从用户，不加海报边框。
- **文字**：默认不画文字、标识、水印。用户明确要标题或招牌时按原文处理，单独检查，不替换成乱码。

## 从主题到生成

看完例图后，确定主体、视角、光线、配色和一条视线引导关系。缺少非关键细节时直接合理选择，不因常规参数反复询问。

把风格描述与具体场景分开写，使用 [提示词模板](references/prompt-recipes.md)。实际出图使用图像生成工具，优先内置 `image_gen`，一张独立作品一个提示词。不要用拼贴、截图裁切或 SVG 代替生成图。仅要求提示词时输出提示词即可，仍先完成例图观察。若生成工具不可用，说明限制；不要擅自转用需额外付费或密钥的 API，也不把提示词报成已生成图片。

著名景点需要可辨识的轮廓、结构和比例：例如桥塔数量、屋顶层次、鸟居形状。对不熟悉的景点核对官方资料；要求高忠实度时使用实际景点照片，分别标注内容参考与风格参考。保留艺术化表达，不把生成图当成精确测绘或现场记录。

批量作品先列简短变化表：主体 / 环境 / 视角 / 天气季节 / 配色 / 引导形状。相邻作品尽量改变其中两项以上。同一地点或统一季节要求下，改变距离和构图；不因“多样性”改写用户主题。

## 成图检查

实际查看成图，确认：

1. 纸纹、不透明色块、手绘边缘和暖冷关系同时成立，不是仅叠一层纸纹滤镜。
2. 主体清楚，没有滑向摄影、光滑 3D 或黑描边卡通。
3. 天气、地点和用户要求一致；地标识别性结构没有明显错误。
4. 批量图不只是换颜色、换车辆或重复海岸弯道，作品数量与独立文件数一致。

漂移时指出具体偏差，再针对它修正：去掉写实高光、增大色块、简化细节、收拢强调色或换构图，不不断堆叠形容词。保存最终图与提示词。生成网站、发布或安装其他工具不属于这个技能的默认动作。
