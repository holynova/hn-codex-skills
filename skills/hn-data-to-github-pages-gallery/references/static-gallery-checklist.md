# Static Gallery Checklist

- Data has stable IDs, titles, dates, tags, source URLs, batch/source labels, image paths, and status.
- UI has a default sort that matches the content type.
- Search checks title, description, tags, and any user-important fields.
- Batch/table switches preserve the user's ability to compare old and new data.
- Card and detail views avoid broken image links.
- Mobile controls are compact and reachable.
- Local verification checks item count and core interactions.
- Live verification uses a cache-busting GitHub Pages URL.
