# 图片加载验证

先确定项目目标和现有基线。不要为截图把所有图片变 eager，也不要用旧注释当指标。源码检查、资产字节统计、模拟状态测试和真实浏览器测量分别报告。

## 资产

- 数据引用中的每个原图、缩略图与详情图是否存在、真实格式/尺寸是否匹配；中文、空格、大小写、非 PNG 路径和嵌套目录是否正确。
- 对比同一素材组原图与衍生图字节及画质；保留原图，不重压缩后覆盖。
- 源文件变化、编码参数变化及第二次重复运行是否更新/复用正确；未涉及分类数据保持不变。

## 浏览器行为

| 场景 | 观察 |
| --- | --- |
| 首屏冷缓存 | 请求少量当前列表缩略图；必要 LCP 不 lazy；无正常路径原图洪峰 |
| 首屏热缓存 | 资源复用情况；不以 encodedBodySize 充当实际 transfer bytes |
| 慢网详情 | 缩略图保持可见，高清加载/解码后升级，无先清空等待 |
| 快速 A→B→A 翻页 | 请求迟到不覆盖当前图；关闭/卸载后不更新旧视图 |
| 图片/格式/解码失败 | 每级最多尝试一次，保留有效缩略图，错误占位不循环 |
| 长滚动 | 小批追加、结束停止；DOM/内存增长可接受；无重复 observer |
| 搜索/切分类 | 防抖、数据/计数重置正确，旧列表图片不混入新列表 |
| 不支持 decode/IntersectionObserver | load/error 与加载更多回退可用，不停在首批 |
| 桌面/375–430px移动端与高 DPR | 尺寸预留、清晰度、裁切、触摸翻页与减少动态效果正确 |
| 下载/分享/批量导出 | 用户触发才加载原图；文件可打开、状态恢复、CORS正确，无重复任务 |

回退故障可在本地/测试环境阻断 thumbnail、detail、original 或用损坏资源模拟；不要破坏线上素材。观察网络请求种类和数量，不只看截图。

## 指标口径

前后固定设备/视口、CPU/网络条件、路由、样本素材、测量时窗及冷/热缓存。记录首屏图片请求数/实际网络传输、FCP、LCP、CLS、DOM、详情可见到高清升级延迟；可用 PerformanceObserver、DevTools/CDP 或项目现有工具。

区分 transferSize、encodedBodySize、decodedBodySize：0 可能来自缓存或跨源可见性限制，不做 `transferSize || encodedBodySize` 当真实传输量。总量注明是否含文档、脚本与其他资源。LCP/CLS 与固定等待结束不应混为一谈。

重复采样报告成功样本数及中位数/分布；不能将失败测量或缺失 paint 当成 0ms 拉低平均。性能工具不可用时报告源码与资产核对结果，保留性能实测待完成。
