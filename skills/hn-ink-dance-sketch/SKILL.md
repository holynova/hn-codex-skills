# 墨线舞蹈速写

用少量有速度与压力变化的墨线，抓住舞者的重心、扭转和节奏。画面像现场捕捉的一瞬，不是将服装完整描摹的插画。风格保持一致，舞种、人物、衣服和构图可以变化。

## 例图是必需输入

每次使用本 skill，先读 [例图库与观察要点](references/examples.md)，再用可用的图像查看工具实际查看例图。**不能只读图片文件名或文字描述就开始作图。** 单张至少查看 `01-ink-ribbon.webp` 和两张与当前题材相关、轮廓不同的例图；多张系列查看全部六张。

例图属于 skill 的必备资源，必须随包一起安装、发布和分发。文件缺失时先尝试从同一发布版本恢复；无法恢复时明确说明例图缺失，不声称已按完整 skill 执行。生成时选 2–3 张例图作为风格参考输入，明确“只参考笔触、纸张和概括程度，不复制人物、动作或服装”。如果工具只接受会话图片，先打开所选例图再传入；若工具无法接收视觉参考，说明这次只能依靠已查看图片后的文字提炼。

## 风格骨架

- **线是主角。** 细线、顿挫粗线、飞白和断笔交替；有急转、有轻轻带过的弧线。轮廓不必闭合，也不应处处描两遍。拒绝均匀光滑的矢量线。
- **先动势，后人物。** 先用一条主轴概括重心与躯干，再建立肩胯的反向扭转、手脚方向，最后用少量衣褶支持动作。飘带只在服装或舞种需要时出现。
- **黑块少而有位置。** 头发、腰带、衣领、鞋或局部衣料可作几处浓墨锚点；身体和大部分服装仍靠留白成立。避免大片涂黑吞掉姿态。
- **脸与装饰高度概括。** 几笔交代眼、鼻、嘴和视线即可，首饰、褶皱、手指不要成为密集细节。手势需要可读，不要求每个指节写实。
- **纸感轻，留白足。** 默认暖米白或浅象牙色纤维纸，纹理低对比，没有做旧污渍、暗角或相框。周围留出呼吸空间；不靠舞台、风景或光影补足画面。
- **自然有误差，动作仍成立。** 保留速写的疏漏和不对称，保证支撑脚、膝肘、肩胯与头部关系可信，避免额外肢体和重心矛盾。

默认单色黑墨、不加灰色体积塑造，不加题字、印章、水印和边框。用户指定颜色、文字、背景或其他变化时服从用户要求，同时尽量保留线的节奏和概括性。

## 系列变化：换结构，不只换手势

用户要多张时，先为每张确定舞种、服装轮廓、动作重心和构图方向；这份简短矩阵可以直接作为内部生成规格，不需要等待批准。

每张与其他张至少在以下三个维度上有明确差别：

| 维度 | 可用变化 |
| --- | --- |
| 舞种与动作语汇 | 芭蕾延伸、弗拉门戈踏步、蒙古舞展臂、印度古典舞屈膝手势、现代舞地面动作 |
| 服装轮廓 | 短硬纱裙、贴身荷叶边长裙、及膝长袍与靴子、扇形褶布舞服、背心与宽裤 |
| 重心与高度 | 足尖直立、低蹲、侧倾、腾跃、坐地或跪地 |
| 视角与方向 | 正面、侧面、背面回首；左向、右向、水平展开、紧凑低位 |
| 人物与线的力度 | 不同体态、发型、性别；轻盈细线或厚实顿挫，但仍属于同一墨线系统 |

保留用户指定的舞种、服装、性别和数量，在其范围内做变化。不要为凑差异强行替换题材。陌生舞种需要准确服装与手势时查可信资料；只概括可核实的特征，不混搭成想象的“民族服”。

## 作图与检查

使用当前环境的图像生成工具；普通作图优先内置 image_gen，不用 SVG、Canvas 或代码线稿替代。只要求提示词时输出提示词即可。实际作图时每件作品独立调用、独立成图，不把五张画塞进一张拼贴。不要因普通参数或保存路径控制转用需要 API 密钥的后备方式。

读 [提示词模板与修正方法](references/prompting.md)，填入具体舞种、衣服、动作与轮廓。不同作品共享“风格骨架”，各自使用不同的主体规格。生成后实际查看每张：

1. 缩小看能否区分人物轮廓与动作，系列是否又变成同一种长裙、头饰和飘带。
2. 放大看线是否有轻重断续，是否出现过度精致的脸、花纹或均匀矢量线。
3. 看身体是否成立，是否完整保留必要手脚、衣服特征与留白。

发现相似时改舞种、服装结构或动作高度；发现过密时删装饰和衣褶，不仅要求“更简洁”。修改仍用图像生成工具。返回实际完成的数量，明确任何失败或未完成项；项目用图保存进项目，预览图可直接展示。
