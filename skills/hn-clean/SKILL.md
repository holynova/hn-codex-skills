# HN macOS 磁盘清理

根据用户请求确定范围。只问占用或建议时，做只读分析。用户已授权按清单清理时，直接执行清单内的操作，无需再次确认。整库删除、会话永久删除、关闭应用功能和重启各有自己的范围，依据用户的具体指令执行。遇到会改变删除范围或影响唯一数据的歧义，先给出具体路径、内容和影响，继续处理已授权的独立项目。

## 盘点和清理

1. 记录目标卷的可用空间。优先用 Mole 分析和 dry-run 找候选，再用系统工具核实占用、用途及扫描盲区。按实际收益和可恢复性排序。命令和常见类别见[磁盘分析与清理](references/macos-cleanup.md)。
2. 优先处理确认无用的安装包、更新缓存、旧日志和可重建的闲置构建产物。对 Mole 候选逐项确认来源、依赖和恢复方式。执行前重新核实具体路径、别名和当前写入者。遇到构建、部署、更新或服务活动时，保留相关项并记录原因。整目录删除仅作用于核实后的目标路径。
3. 保留唯一原件。按字节验证重复文件，需要多个路径时可考虑 APFS 写时复制克隆。归档后要移除源目录时，先验证归档可读、可恢复，并确认源未在打包期间变化。有损压缩成品即使与源文件页数相同，也无法恢复原始质量。临时目录内的高保真原件也需要按内容判断。
4. 处理 Codex、Antigravity 会话或闲置项目时，按[会话与项目](references/sessions-and-projects.md)分别核实活动时间、作品、Git 状态及恢复条件。用户明确要求先同步或发布时，把这些动作的成功核验放在本地删除之前。

## 延后执行

按用户提供的时区、最早执行时间和目标范围安排。提前运行的其他批次排除整个延后范围及其别名。需要跨会话执行时，使用环境支持的调度工具，记录目标、时间、授权及成功条件。触发后读取已有执行记录和项目说明，复查时间、路径、活动进程与候选项，再处理。一次性任务确认完成后停用，避免重复执行。

## 验收与记录

复测同一卷，核验目标状态和需要保留的内容。报告实际操作、保留或跳过的原因、可恢复内容的位置，以及尚未验证的事项。将目录分配空间、工具估算和同一卷上观测到的可用空间变化分别列出。APFS 克隆、快照、归档占用和后台写入会影响实际变化。多阶段或批量清理时，把逐项记录和前后测量保存在目标目录之外。

核验清理结果所需的关键证据缺失时，暂停受影响的操作。可选核验卡住时，采用与任务相称的替代证据并说明验证边界，继续其他已授权的步骤。
